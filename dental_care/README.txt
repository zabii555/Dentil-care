SMILECARE - Dental Clinic Website (React Frontend)
==================================================
- Pure FRONTEND website - NO backend needed
- Built with REAL React (components, hooks: useState/useEffect)
- Background video in hero section (plays from internet)
- Real clinic / doctor / treatment images included
- Appointment form saves bookings in browser (localStorage)

HOW TO OPEN
-----------
1. Extract this ZIP
2. Just DOUBLE-CLICK index.html  (opens in your browser)
   OR right-click -> Open with -> Chrome/Edge

NOTE: Internet connection is required the first time you open it,
because React loads from CDN and the hero video streams online.

WHAT'S INSIDE
-------------
- index.html      -> React app (JSX components, inline Babel)
- static/style.css -> Styling (clean teal/blue medical theme)
- static/img/     -> 10 real dental images
